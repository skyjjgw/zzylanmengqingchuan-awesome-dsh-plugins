# Repository instructions

- This is a curated, evidence-aware catalog, not a raw scraper.
- Never turn README claims into local test claims.
- Every plugin entry must retain its original repository URL and a review date.
- Never commit API keys, tokens, passwords, OAuth values, private paths, session logs, or screenshots containing them.
- Keep the Chinese README authoritative for the current shortlist; update the English README when the positioning changes.
- Run `node scripts/validate.mjs` before committing.
